# PitchIQ 야구장 분위기 전체 디자인 개선 — 설계

## 배경

게임 HUD 강화(`2026-08-04-game-hud-ui-design.md`) 이후 "이제 야구느낌나게 하는 사이트 전체적인
디자인 개선도 들어가보자"는 요청을 받음. 스타일 방향은 이전 두 차례 개편에서 확정한 스포츠 게임
HUD + 네이비·퍼플·골드 팔레트를 그대로 유지하며, 지금까지 손대지 않은 영역(배경, 타이포그래피,
사이드바, 하단 통계 카드)에 야구장 분위기를 더한다. 비용 부담을 고려해 "사이트 전체를 한 번에,
중간 규모"로 범위를 확정.

## 목표

1. 페이지 배경에 은은한 야구장 필드 라인 분위기 추가
2. 스코어보드성 큰 숫자/코드 요소에 스포츠 스코어보드 타이포그래피 적용
3. 사이드바에 야구 스티치 모티프 + 정돈된 카드 스타일 적용
4. 하단 통계 카드에 아이콘 + 시맨틱 컬러로 구분감 부여

## 비범위 (Non-goals)

- 레이아웃 구조(컬럼 배치, 카드 순서) 변경 없음
- 색상 팔레트(네이비·퍼플·골드) 재정의 없음 — 새 배경/타이포도 이 팔레트 안에서만 조정
- 지난 두 차례 개편 요소(스코어보드 팀컬러, 원형 게이지, COMBO, LIVE 배지, 리빌 애니메이션)는
  변경하지 않음
- 예측 로직, `session_state` 필드, 영상/싱크 로직 변경 없음
- 이미지 에셋 추가 없음 — 전부 순수 CSS(그라데이션/SVG data-uri 배경)로 구현
- 폰트는 기존 Inter 포함 총 2개까지만 (`web/performance.md` 규칙 준수)

## A. 배경 분위기

- `[data-testid="stAppViewContainer"]` 배경을 단색(`#080e1a`)에서 상단→하단 네이비 그라데이션으로:
  ```css
  background:
    radial-gradient(ellipse 80% 50% at 50% -10%, rgba(59,130,246,.06), transparent),
    linear-gradient(180deg, #0a1120 0%, #080e1a 40%, #05080f 100%);
  ```
- 다이아몬드형 필드 라인은 진짜 SVG 대신 CSS `linear-gradient` 스트라이프 2장으로 파울라인을
  근사해 아주 옅게(투명도 3~4%) 표현 — 별도 에셋 파일 없이 인라인 처리.
- `background-attachment: fixed`로 스크롤해도 고정되게 하여 은은한 배경 느낌 유지.

## B. 타이포그래피 — 스코어보드 폰트

- Google Fonts `Oswald`(condensed, weight 700/900)를 `@import`로 추가, `font-display: swap`.
- 적용 대상(전부 기존 클래스 재사용, 클래스 내 `font-family`만 추가):
  `.team-score`, `.pitch-code`, `.conf-gauge-code`, `.hero-title`, `.intro-logo`, `.inning-box`
- 본문/설명 텍스트(`body`, `.pitch-name`, 캡션 등)는 기존 Inter 그대로 — 총 2개 폰트 유지.

## C. 사이드바 아이덴티티

- 로고(`⚾ PitchIQ`) 아래 구분선을 기존 `st.divider()` 대신, 야구공 스티치를 연상시키는 점선 두 줄
  (`border-top: 1px dashed`, `border-bottom: 1px dashed`, 사이 간격 3px)로 교체한 커스텀 구분자
  `<div class="stitch-divider">`.
- "경기 현황" / "구종 범례" 섹션을 각각 `.sidebar-card`(신규 클래스, `.panel-secondary`와 톤 통일 —
  옅은 배경 + 얇은 테두리 + 라운드)로 감싸 시각적으로 구획을 나눈다.

## D. 하단 통계 카드 — 아이콘 + 시맨틱 컬러

기존 4개 카드(분석 투구/패스트볼/변화구/평균 구속)에 아이콘과 값 색상을 추가:

| 라벨 | 아이콘 | 값 색상 |
|---|---|---|
| 분석 투구 | ⚾ | 기존 흰색 유지 (중립 지표) |
| 패스트볼 | 🔴 | `#ef4444` (PITCH_META FF 계열과 동일 색) |
| 변화구 | 🔵 | `#3b82f6` (PITCH_META SL 계열과 동일 색) |
| 평균 구속 | 💨 | `#fbbf24` (골드 액센트) |

마크업은 기존 `st.columns(4)` 루프에 아이콘/색상 매핑 리스트를 추가하는 방식으로, 구조 변경 없이
값만 확장.

## 구현 파일

- `streamlit_app/app.py`만 수정 (CSS `@import` 및 배경/타이포/사이드바 카드 클래스 추가, 사이드바
  마크업에 스티치 구분선·카드 래퍼 적용, 하단 통계 카드 루프에 아이콘/색상 매핑 추가)
- 신규 파일 없음

## 검증

- `streamlit run streamlit_app/app.py`로 로컬 실행 후:
  - 배경에 은은한 그라데이션·라인이 보이되 텍스트 가독성을 해치지 않는지 확인
  - 점수/구종코드/신뢰도 게이지 코드 등 큰 숫자 요소에 Oswald 폰트가 적용됐는지 확인
  - 사이드바 구분선이 스티치 느낌으로 바뀌고, 경기 현황/구종 범례가 카드로 구획됐는지 확인
  - 하단 통계 카드 4개가 아이콘 + 서로 다른 색상으로 구분되는지 확인
- 회귀 확인: 지난 두 차례 개편 요소(스코어보드, 원형 게이지, COMBO, LIVE, 리빌 애니메이션)와
  영상 재생·투구 네비게이션이 그대로 동작하는지
